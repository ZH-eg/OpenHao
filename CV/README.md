
# OCR Template Matching - 信用卡号码识别系统

## 项目简介

本项目是一个基于 OpenCV 的信用卡号码识别系统。系统采用模板匹配（Template Matching）技术，能够自动从信用卡图像中提取并识别卡号，同时根据卡号首数字判断信用卡类型（支持 American Express、Visa、MasterCard 和 Discover Card）。该方案无需依赖深度学习模型，通过传统的图像处理与模板匹配算法即可实现高效的卡号识别。

## 功能特性

- **自动卡号识别**：自动定位并提取信用卡图像中的数字区域。
- **卡类型判断**：根据卡号首数字自动识别 American Express、Visa、MasterCard 或 Discover Card。
- **模板匹配算法**：基于 OCR-A 字体模板进行高精度数字匹配。
- **图像预处理流水线**：集成礼帽操作、Sobel 梯度、Otsu 二值化等经典图像处理技术。
- **轮廓智能筛选**：基于宽高比和尺寸自动过滤非数字区域。
- **灵活排序支持**：支持多种轮廓排序方式（从左到右、从右到左、从上到下、从下到上）。

## 使用方法

主程序通过命令行参数指定输入图像与模板文件。

**命令行参数说明：**

| 参数 | 说明 |
|------|------|
| `-i, --image` | 输入信用卡图像的路径（必填） |
| `-t, --template` | 模板 OCR-A 图像的路径（必填） |

**运行示例：**

```bash
python ocr_template_match.py --image images/credit_card_01.png --template ocr_a_reference.png
```

## 工作流程

1. **模板预处理**：读取模板图像，进行灰度化与二值化，提取数字轮廓并按尺寸裁剪、缩放至统一大小（57×88），存入字典备用。
2. **图像预处理**：读取输入图像并缩放至宽度 300px，经灰度化、礼帽操作突出明亮区域、Sobel 水平梯度计算、归一化及闭操作后，使用 Otsu 阈值进行二值化。
3. **轮廓提取与筛选**：在预处理后的图像中寻找轮廓，保留宽高比在 2.5~4.0 之间、宽度 40~55、高度 10~20 的有效数字区域。
4. **数字分组**：对筛选出的轮廓进行 ROI 提取与二次 Otsu 二值化，定位具体数字轮廓并排序。
5. **模板匹配**：将每个数字区域缩放至与模板相同尺寸，使用 TM_CCOEFF 方法与所有模板进行匹配，取得分最高者作为识别结果。
6. **结果输出**：打印信用卡类型与完整卡号，并在原图上绘制矩形框及识别文字。

## 核心算法说明

本项目的核心是**模板匹配（Template Matching）**。算法通过将待识别的数字图像（ROI）与预定义的 OCR-A 字体模板进行滑动窗口比对，计算两者的相似度系数（采用 cv2.TM_CCOEFF 方法）。相似度得分最高的模板即被判定为当前数字。结合图像形态学处理（如礼帽操作提取亮区、闭操作连接断裂笔画），系统能在复杂背景下准确定位并识别卡号。

## 注意事项

- **模板一致性**：模板图像必须使用标准的 OCR-A 字体，且数字排列顺序需与代码中的处理逻辑一致。
- **图像质量**：输入图像应清晰、光照均匀。过度倾斜、模糊或反光严重的图像可能导致识别失败。
- **尺寸适配**：主程序默认将输入图像宽度缩放至 300px 进行处理，若原始图像比例差异过大，可能影响轮廓筛选效果。
- **卡类型支持**：当前仅支持以 3、4、5、6 开头的四种信用卡类型，其他卡种需自行扩展映射字典。
- **依赖版本**：建议使用较新版本的 OpenCV，以确保形态学操作与模板匹配函数的兼容性。
